# Laundry Service Hero Section

## About the Project
This project is a responsive hero section for a laundry service website, built using HTML and CSS. It includes a navigation bar, a hero section with text and an image, and a booking button with a hover effect.

## Features
- Navigation bar with Home, Services, About Us, and Contact Us links
- Hero section with a heading, description, and laundry image
- "Book a Service Today" button
- Hover effect that increases the button's size and tilts it
- Responsive layout for desktop, tablet, and mobile screens

## Technologies Used
- HTML5
- CSS3

## Project Structure
```text
laundry-service/
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Hover over the booking button to see the effect.

## Hover Effect
When the user hovers over the booking button, it smoothly increases in size and tilts slightly to the left using CSS `transform`, `rotate()`, `scale()`, and `transition`.

## Responsive Design
CSS media queries are used to adjust the layout for desktop, tablet, and mobile screens.
